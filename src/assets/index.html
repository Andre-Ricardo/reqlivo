Scripts JavaScript

API rq.env, rq.request, rq.response, test e expect. Execução síncrona com limite de tempo.

Asserções declarativas

Expressões como res.status e res.body.user.name. Operadores: eq, neq, gt, gte, lt, lte, contains, startsWith, endsWith, matches, in, isString, isNumber, isBoolean, isArray, isObject, isNull, exists, notExists, lengthEq.

Contratos rápidos

  • Variáveis: {{nome}}, com precedência runtime → requisição → pasta → ambiente → coleção.
  • Auth: herda da requisição para a pasta folha até a coleção.
  • Scripts: pré, pós e testes; logs e mensagens de teste são redigidos.
  • Runner: ausência de testes resulta em executada, não passou.
  • Projeto é a fonte de verdade; cache, logs e lixeira ficam em .reqlivo/.

Alterações não salvas

Escolha como continuar antes de sair desta edição.

Rascunhos protegidos

Rascunhos ficam em .reqlivo/drafts/ e nunca alteram o YAML até você salvar. Credenciais digitadas no editor podem aparecer nesse arquivo local.

Conflito de revisão

O arquivo mudou fora do Reqlivo. Compare as versões antes de decidir.

Nenhuma opção sobrescreve o disco sem confirmação explícita. Uma nova alteração externa gera outro conflito.

Lixeira

Itens excluídos preservam bytes e ID. Não há esvaziamento nem exclusão permanente nesta versão.

Migração e recuperação

A coleção precisa de uma migração confirmada antes de abrir.
